# Interface: MetadataFieldDefinition

Definition for a metadata field that will be stored as a separate column.

## Properties

### name

> **name**: `string`

Name of the metadata field

***

### nullable?

> `optional` **nullable**: `boolean`

Whether the field can be null (default: true)

***

### type

> **type**: [`MetadataFieldType`](../type-aliases/MetadataFieldType.md)

Data type for the field
